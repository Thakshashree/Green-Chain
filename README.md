# Green Chain 🌱 - Sustainable Supply Chain Tracker

A transparent supply chain platform to track products from farm to consumer.

## How to Run
1. git clone https://github.com/Thakshashree/Green-Chain.git
2. npm install
3. Copy .env.example to .env and add your keys
4. npm run dev

## Security Note
.env file is not uploaded to GitHub for security. See .env.example for format.
